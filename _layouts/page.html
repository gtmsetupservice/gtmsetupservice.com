Use a Liquid comment, never an HTML comment, for notes in a layout: Liquid expands its tags inside HTML comments, and an HTML comment in the injected page body would close this one early (comments do not nest). Liquid comments are stripped before any HTML exists, so neither happens. Markdown in the page body is rendered by Jekyll before the layout injects it, so it is never nested inside raw HTML in the source file — which is what stops kramdown parsing it. Pages wanting prose should use this layout rather than wrapping their own body in a container element. {% endcomment %}
