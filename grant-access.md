    <div class="font-mono text-[.72rem] text-slate-light mb-3">Audit setup · takes about 5 minutes</div>
    <h1 class="text-[clamp(2rem,4.6vw,3.1rem)] leading-tight">
      Grant access for your GTM / GA4 / Search Console audit
    </h1>
    <div class="stripe-rule" role="presentation"></div>
    <p class="text-[1.14rem] text-slate">
      To run your audit we need access to three Google tools: Tag Manager, Analytics (GA4),
      and Search Console. Add our account —
      <span class="font-mono text-[.95em] bg-asphalt/5 px-1.5 py-0.5 rounded">admin@gtmssllc.com</span>
      — to each one below, then come back and submit your audit request form.
    </p>
  </div>
</section>

<section class="py-14 md:py-[72px]">
  <div class="max-w-6xl mx-auto px-5 md:px-7 grid lg:grid-cols-3 gap-10">

    <div>
      <span class="font-mono text-[.78rem] text-stripe block mb-3 font-medium">Step 1</span>
      <h2 class="text-[1.08rem] font-semibold mb-3 leading-snug">Google Tag Manager</h2>
      <ol class="text-[.95rem] text-slate leading-relaxed list-decimal pl-5 space-y-2">
        <li>Go to <a href="https://tagmanager.google.com" target="_blank" rel="noopener" class="text-stripe underline underline-offset-4 focus-ring">tagmanager.google.com</a> and open your account.</li>
        <li>Click <strong>Admin</strong> in the top navigation.</li>
        <li>Under <strong>Account</strong>, click <strong>User Management</strong>.</li>
        <li>Click the <strong>+</strong> button → <strong>Add users</strong>.</li>
        <li>Enter <code class="font-mono text-[.92em]">admin@gtmssllc.com</code>, set account permission to <strong>Admin</strong>, and set <strong>Publish</strong> permission for each container.</li>
        <li>Click <strong>Invite</strong>.</li>
      </ol>
    </div>

    <div>
      <span class="font-mono text-[.78rem] text-stripe block mb-3 font-medium">Step 2</span>
      <h2 class="text-[1.08rem] font-semibold mb-3 leading-snug">Google Analytics (GA4)</h2>
      <ol class="text-[.95rem] text-slate leading-relaxed list-decimal pl-5 space-y-2">
        <li>Go to <a href="https://analytics.google.com" target="_blank" rel="noopener" class="text-stripe underline underline-offset-4 focus-ring">analytics.google.com</a>.</li>
        <li>Click <strong>Admin</strong> (gear icon, bottom left).</li>
        <li>Under the <strong>Property</strong> column, click <strong>Property Access Management</strong>.</li>
        <li>Click the <strong>+</strong> button (top right) → <strong>Add users</strong>.</li>
        <li>Enter <code class="font-mono text-[.92em]">admin@gtmssllc.com</code> and select role <strong>Administrator</strong>.</li>
        <li>Click <strong>Add</strong>.</li>
      </ol>
    </div>

    <div>
      <span class="font-mono text-[.78rem] text-stripe block mb-3 font-mediim">Step 3</span>
      <h2 class="text-[1.08rem] font-semibold mb-3 leading-snug">Search Console</h2>
      <ol class="text-[.95rem] text-slate leading-relaxed list-decimal pl-5 space-y-2">
        <li>Go to <a href="https://search.google.com/search-console" target="_blank" rel="noopener" class="text-stripe underline underline-offset-4 focus-ring">search.google.com/search-console</a>.</li>
        <li>Select your property (your website).</li>
        <li>Click <strong>Settings</strong> in the left sidebar.</li>
        <li>Click <strong>Users and permissions</strong>.</li>
        <li>Click <strong>Add user</strong>.</li>
        <li>Enter <code class="font-mono text-[.92em]">admin@gtmssllc.com</code>, set permission to <strong>Owner</strong>.</li>
        <li>Click <strong>Add</strong>.</li>
      </ol>
    </div>

  </div>

  <div class="max-w-6xl mx-auto px-5 md:px-7 mt-8">
    <div class="border-l-[3px] border-stripe bg-asphalt/5 px-5 py-4 rounded text-[.93rem] text-slate max-w-prose">
      If you're not already an <strong>Owner</strong> of the Search Console property yourself, you may
      only be able to grant <strong>Full User</strong> access instead — that's still enough for us to
      run the audit, just note it on your audit request form.
    </div>
  </div>
</section>
